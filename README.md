# Salesforce Marketing Cloud Learning Hub

A practical, original study library for Salesforce Marketing Cloud (SFMC).

## Start here

1. Read [Foundations and administration](course/01-foundations-and-admin.md).
2. Build an email in [Email and Content Builder](course/02-email-and-content.md).
3. Model data and automate a repeatable workflow in [Data, Automation Studio and Journey Builder](course/03-data-automation-and-journeys.md).
4. Capture and manage preferences in [CloudPages and scripting](course/04-cloudpages-and-scripting.md).
5. Connect, deploy and monitor in [Integration and deployment](course/05-integration-and-deployment.md).
6. Complete the [practice labs](course/practice-labs.md) and save evidence of your work.

## Learning path

| Phase | Focus | Outcome |
|---|---|---|
| 1 | CRM, SFMC architecture, HTML/CSS, admin | A safe and well-organised business unit |
| 2 | Email Studio and Content Builder | A tested, personalised email campaign |
| 3 | Data modelling, SQL, automation and journeys | A reusable customer lifecycle workflow |
| 4 | CloudPages, AMPscript and SSJS | A consent-aware form or preference centre |
| 5 | APIs, transactional journeys and deployment | A monitored integration and release plan |

## Study loop

**Learn → build → test → explain → document.**

For every activity, record the audience, data source, business rule, test evidence, result and one limitation. That habit turns a tutorial exercise into portfolio evidence.
